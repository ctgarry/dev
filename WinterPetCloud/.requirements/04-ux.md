# 04-ux — Entry Points, Frames, Flows, Microcopy Intent

## Entry Points
- Slash `/petcloud`
- Keybind “Open Pet Cloud”
- Minimap button
- Options panel tab “Pet Cloud”

## Frames
1. **Main Browser**
   - Left: Tag Cloud (scrolling, weighted, keyboardable)
   - Top: Search box + Scope toggle (Owned / Unowned / All) + Logic (AND/OR)
   - Right: Result list (virtualized), details pane on select
   - Bottom: Bookmark bar (save, load, manage, export, import)
2. **Microframe Quick-Pick (optional)**
   - Last-used bookmark name, 1-click summon favorite pet from results.

## Flows
- **F1 Open & Autoload:** Open → detect inventory → render cloud (≤100 ms) → focus search.
- **F2 Filter:** Click tag → update results → update cloud weights → show active pill.
- **F3 Multi-tag:** Click second tag → AND by default → show result count change live.
- **F4 Bookmark:** Click Save → name dialog → write to saved vars → toast “Saved”.
- **F5 Share (account):** Saved bookmark auto-appears on other alts after reload.
- **F6 Export/Import:** Export → copy string (with checksum). Import → paste → preview name/tags/scope → confirm → bookmark added.
- **F7 Clear:** Click “Clear All” → remove pills, reset scope/sort to defaults.

## Microcopy Intent (i18n keys referenced in 06)
- Titles, toasts, errors, and tooltips referenced by key only; keep tone brief, helpful, and non-cutesy.
