
# Requirements‑First Process (Overview)

1. **Charter** — problem, vision, scope, non‑goals, constraints, personas.
2. **User Stories** — AC with Given/When/Then, MoSCoW priority.
3. **FR/NFR** — testable rules, numbered (FR‑#, NFR‑#).
4. **Data Model** — entities, defaults, migration, back‑compat.
5. **UX** — entry points, frames, flows, microcopy intent.
6. **Implementation Plan** — file touchpoints, ≤6 small steps.
7. **i18n Keys** — all user‑visible strings live in i18n files.
8. **Acceptance** — verification list mapped to FRs.
9. **Test Plan** — smoke, feature, edge cases.
10. **Codex Steps** — strict light‑diff tasks; STOP/WAI after each.
